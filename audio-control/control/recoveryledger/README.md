# Audio control R1 — immutable intent journal experiment

**Synthetic, nonproduction, no physical device or OS permissions.** A bounded Go stdlib file-backed proof that persists an immutable START intent *before* effects and classifies interrupted operations conservatively on process restart. The prior pure R0 reducer lives in [PR #723](https://github.com/SemperSupra/stable-character-pipeline/pull/723), with crash-counterexample tests in [#728](https://github.com/SemperSupra/stable-character-pipeline/pull/728). This branch owns only `audio-control/control/recoveryledger/**` and its dedicated public workflow.

Use `go test -race -count=1 ./recoveryledger` from `audio-control/control`. Its tests prove: non-overwriting immutable intent, replay suppression for same identity/digest, conflict on reused operation key with altered plan, restart yields unknown pending rather than permission to replay START, original stop receipt comparison, symlink/partial record fail-closed. The package **does not play sound** and its `MayIssueStart` recovery field is always false.

Critical **NOT PROVEN**: process-local calls cannot authenticate host observations; caller-provided `HostEvidenceSHA256` is not a real signed/verified event. File creation and `Sync` are not an atomic SQLite transaction nor independently qualified power-failure durability across operating systems; directory entry fsync, storage guarantees, concurrent writers, disk exhaustion, remote filesystems and TOCTOU remain unresolved. No claim of exactly-once physical effects, proven host silence, or independently durable STOP. For production investigate the smallest supported SQLite WAL/transactional-outbox adapter and OS audio supervisor, with human authorization, recovery and physical tests.

Any future production adapter must reject an agent's attempt to forge `RecordHostStopped` and must require matching signed/authenticated OS device and lease identity. No merge, signing, release, audio recording, or patient/voice files authorized.
