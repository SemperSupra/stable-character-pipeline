# Original authored BVH parser and paired-clock qualification

Source-only research implementation; Go standard library. Bounded BVH hierarchy, true ordered local rotation matrices and FK, exact decimal frame period and explicit metre conversion; original 3-frame synthetic A/B clips only. No real original motion-capture bytes, protected character or human source, PMX/VMD target semantics, independent camera issuer, true synchronization, or physical gait acceptance.

The Go **library** parses data with a declared classification; declaration alone is not a rights/admission proof. The **CLI** independently pins exact authored fixture SHA256 bytes and rejects all other inputs, retaining the S0 rights/runner prerequisite for any actual CMU or Cologne source. S0 rights must precede S1 original-file ingestion. All original character sources/runner remain held.

Humans: this README and CI run logs. Automation: JSON output schema and deterministic non-overwrite behavior. Agents: `-capabilities` read-only discovery. Native qualified status must be checked at the exact PR commit and is never a release or scientific CPE promotion.

Use `go test ./... && go test -race ./... && go vet ./...` then:
`go run ./cmd/bvhqual -source examples/original-synthetic-A.bvh -other examples/original-synthetic-B.bvh -meters-per-unit 0.05 -out receipt.json`.
Standalone output is `CLOCK_COMPATIBLE_ORIGINAL_SYNTHETIC_ONLY_SESSION_SYNC_UNKNOWN`, not a proven source session sync.
