# Original authored VMD v2 serialization boundary

A standalone source-safe Go stdlib VMD v2 binary writer and strict Go parser, with a completely separate Python stdlib structural reader. Pinned upstream byte-layout references: https://github.com/dskjal/OpenMMD/blob/main/docs/specification/vmd-specification.md and https://github.com/oguna/MMDFormats/blob/master/MikuMikuFormats/Vmd.h . The exact byte layout is 30-byte v2 header, 20-byte synthetic ASCII model name, 4-byte keyframe count, 111-byte records (15-byte bone name, 4-byte frame, 12-byte position, 16-byte quaternion, 64-byte four-channel authored interpolation controls (X/Y/Z/rotation at 16-byte strides; native MMD runtime still unqualified)), five zero-count unsupported sections. Original authorship, 93 synthetic 30fps keyframes over 1 second, 3 abstract bone names, no imported source motion or actual PMX bindings.

**Critical holds**: ASCII only, not Shift-JIS general international name coverage; interpolator placeholder is structurally preserved but not playback-accepted; no genuine model rig, measured source ASF/AMC/BVH, VMD reader compatibility in MMD itself, no skin/contact/anatomy/identity, no multi-engine product or R009 acceptance. This workcell is the first source-to-native **binary serializer/independent reader format seam**, not a real motion-to-rig success. All negative controls must reject corruption and overclaims. Three audience paths: readme human, JSON automation, -capabilities agent read-only.
