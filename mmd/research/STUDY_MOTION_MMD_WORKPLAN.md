## First source-backed tests and what each proves

- **CMU `05_02`** expressive arms + pirouette: source-to-MMD upper-body/rhythm/turn test. **`05_11`** sideways steps + pirouette: root displacement/foot slide/turn test. **`56_04`** salsa (source index indicates 60 fps): timebase/rhythm test. **`02_01`** walk: unstyled gait baseline. These trial names were observed in official CMU index. Exact current raw download URL, byte SHA, public CPU source-specific admission and actual MMD VMD generation **remain NOT_RUN**. The original official grant is 'free for all uses' with restriction against selling directly even in converted format; do not infer unrestricted asset republication. Source has no *provided* VMD; converter must do actual retarget.
- **Cologne BVH/C3D:** official TH Köln CC BY 4.0 measured motion and annotation grant; next verify one actual downloadable recording and attribution before conversion.
- **AIST++**: 3D annotations CC BY 4.0; video/music explicitly separately controlled by academic-use AIST terms, SMPL model license independent, external `.pkl` unsafe deserialization prohibited. 60fps original annotations; explicit actor/choreography/music split ancestry. No music copied to demonstration.
- **Northumbria 2010 / McCarty et al. 2017**: actual literature movement-parameter mining may generate synthetic hypotheses with a clear `SYNTHETIC_STUDY_INSPIRED` label; only published avatar video confirmed for 2017, not original Vicon capture files. Video-to-pose later yields `ESTIMATED_FROM_VIDEO` with depth/occlusion uncertainty, **not** original measured mocap. Unmeasured thigh/hip asymmetry is not source-person demographic classification.
- **AMASS / other restricted sources:** do not acquire or run publicly until rights, use and no-redistribution gates separately grant; motion/metadata can be cataloged without copying content.

## DoE / first failures / source rights

Produce controlled source→reference skeleton→target skeleton→VMD/PMX/GLB test pairs. Negatives: forged file SHA/license; duplicate actor/capture/choreography leakage; wrong FPS/phase; centimeters as meters; axis inversion and handedness; nonunit quaternions or bad Euler order; root drift; mapping omitted arm/foot IK; rigid bone stretch; frozen animation; impossible labelled contact. **Do not use an observed attractive-motion metric as an assertion about an individual's ethnicity, status, quality, or traits.** Culturally named motifs remain independent hypotheses with provenance, context and competing explanations.

Avoid a second scheduler or catalog authority. Human gets original-source rights table, source-tagged motion previews and editable Blender/MMD files; automation gets `go run mmd/research/study_motion_admission.go -catalog ... -out ...`, machine PASS/FAIL/NOT_RUN and negative controls; agent gets existing public DLE #19/#29 and separately held private human-source authority and immutable source/runner/rights receipts. A green metadata check does **not** mean any measured source entered public GitHub or a real VMD conversion completed.
