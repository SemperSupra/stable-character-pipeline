# Streaming paired envelope

Same HOLD-only diagnostic as the pinned batch observer. Two UTF-8 JSONL files: first line is the existing packet header without rows; subsequent lines are exact tick rows in order. Run `python3 research/r009-streaming-envelope/stream_envelope.py --reference ref.jsonl --candidate cand.jsonl --windows '[[50,70]]' --out report.json`. Fail closed on missing/extra ticks, mismatched stable IDs, nonfinite/duplicate JSON, protected classification or line larger than 8 MiB. Retain only current/previous track state and maxima; O(vertices) memory plus clock schedule, not O(vertices × frames). Deterministic tie behavior compared against original batch oracle.
