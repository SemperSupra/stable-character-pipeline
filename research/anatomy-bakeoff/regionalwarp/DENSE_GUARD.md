# R036 dense Jacobian + numerical derivative qualification

Independent additive workcell stacked on source-clean 3D RBF registration draft #572 exact head `f321c178c13e9a46c74f8a864843c03dc1a3b846`. Its current RBF candidate tests Jacobian only at a limited set of training and held-out landmarks and selected pair midpoints. A local Gaussian displacement can have Jacobian determinant exactly +1 at a training center but become negative a few centimetres away. This is a real numerical safety blind spot when considering future full-body organ positioning.

The additive guard computes the actual analytic local deformational determinant across a finite **9×9×9 grid** spanning the landmark bounding box with an 80mm margin. It also independently recomputes the determinant by symmetric finite differences of the actual deformation function at four representative samples. Return `HOLD_DENSE_JACOBIAN_OR_STRAIN` if any grid cell violates prescribed positive strain bounds, or `HOLD_ANALYTIC_NUMERICAL_JACOBIAN_DISAGREE` when derivatives conflict. The parent held-out validation remains a separate hard gate; a passing dense grid never waives it.

Hostile original synthetic example creates a narrow Gaussian 0.3m displacement; the Jacobian is 1.0 at its center but becomes negative away from the center. The dense grid must detect actual local folding and fail. Tests also enforce 5–17 sample axes (limit 4,913 samples), sane domain extents, and nonfinite rejection. No real-person landmarks, HuBMAP source bins or private anatomy are processed.

**Limits:** a finite grid is not a mathematical proof of global injectivity or absence of interpenetration between different organs, let alone correct anatomy, tissue constitutive law, contact, render shape, or photorealism. Even a source-backed landmark solve needs reviewed rib/pleura/diaphragm containment and deformation stress tests before L1 or L2. All work remains DRAFT/unmerged, on free hosted Go CPU using only source-clean synthetic geometry, no protected images, model weights, private minutes, paid cloud or release.
