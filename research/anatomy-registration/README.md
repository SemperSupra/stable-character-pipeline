# R036 reference-cohort HRA skin → native MPFB coarse alignment probe

**Why this exists:** The #555 real HRA lung's original 67 source-mesh triangles were merely scaled to 0.30m near a native MPFB spine bone. Before claiming organ placement, test whether HRA 3D reference **skin and lung from the same v1.2 Visible Human Male cohort** actually share the same unmodified source coordinate frame, then derive and falsify a candidate transform to a genuine MPFB external surface. This is a registration-preflight and **not** a trained/landmark-qualified anatomical fit.

Source pinned upstream MPFB2 GPL code and separately CC0 core assets from existing #555: `9de0707fdc88438d7c53a1a2ac7937d9221e2431`.
HuBMAP CC BY 4.0 source organs: official CCF Reference Object Library release v1.2, male lung `VH_M_Lung.glb` pinned SHA256 `e64351b72b0bc5289a4dc32ba2b402b9c974f9ec0b1972bf06b436864f917913`; male **skin** `VH_M_Skin.glb` source SHA256 MUST be observed and pinned to exact downloaded bytes on second cloud run. Source URLs: https://cdn.humanatlas.io/hra-releases/v1.2/models/VH_M_Skin.glb and https://cdn.humanatlas.io/hra-releases/v1.2/models/VH_M_Lung.glb . Rights: https://hubmapconsortium.github.io/ccf/pages/ccf-3d-reference-library.html ; skin DOI `10.48539/HBM369.SBSP.863`, lung DOI `10.48539/HBM787.FWXN.723`. Credited authors Kristen Browne and Heidi Schlehlein.

The Blender script imports HRA external skin and matching lung source **without arbitrary prior fit**, records their absolute 3D bounds/overlap and original source mesh counts, then tests 48 axis-permutation/sign possibilities against the MakeHuman *modifier-evaluated* body using approximately 3,200 sampled surface points and symmetric closest-vertex p95. Proper rigid-handed rotations (24) are separately ranked against 24 improper mirrored/reflected orientations, with source-skin vertical height as the only *uniform* scaling factor. It creates separate **NOT_ADMITTED** candidate derived lung meshes in an independently saved .blend, with original scene/rig and old provisional anatomy untouched, then tests fresh-process reopening and provenance. Reports source/reference bounding checks, center and score. It does not perform 3D anatomical landmarks, side-label preservation QA, nonlinear deformation, ribcage containment, collision, donor medical truth or real tissue physics. A low nearest-point error does not validate pulmonary anatomy. No "accepted" registration without explicit thoracic fiducials and physics.

Run only on disposable free-tier Linux CPU public workers for openly licensed source geometry (65MB per-asset max), no protected named identities, source GLBs or generated derived scenes uploaded to public Actions artifact/repo; retain textual SHA/metrics/DLE. This workcell is stacked on immutable #555; no merge/deploy/release.
