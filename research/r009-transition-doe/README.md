# Original transition shape bake-off

Six native saved/reopened Blender 5.2.4 treatments: linear, cubic smoothstep and quintic minimum-jerk position profile, each with 10- and 20-frame rise/fall halves, identical 30 mm root correction and counter-translation of left shoe proxy. All use the same quarter-frame key grid per duration, explicit native linear or cubic Hermite handles, independently evaluated at integer and 1/32-frame dense times. The separate verifier checks expected polynomial position, per-foot material motion, speed, acceleration, exact clock and unchanged control actor. The quintic is realized via piecewise cubic Hermite approximation, not an exact Blender quintic primitive. This study does not solve gait: opposite-foot motion remains, duration can exceed an actual support window, and physical acceptance is held. No original human or protected assets, no binary uploads. Retain measured tradeoffs rather than pick a profile solely by acceleration.
