## Three independent workcells
1. **Morphology**: compare landmark vectors using explicit units, camera-projection caveat, uncertainty bands and distinct identity/time-state layers. A weighted mean cannot excuse a failed critical landmark; hard-gate symmetry and unit mismatch.
2. **Wardrobe**: represent footwear sole rise, upper-garment retention, trouser clearance, fit and material as a *time-indexed outfit*, never permanent identity. Reject conflicting licensing, penetration and zero-contact/large-skate candidates even if appearance scoring is high.
3. **Soft tissue**: secondary dynamics acceptance must distinguish solver test pass from physical calibration. Verify damping/finite signal, repeatability and no NaNs; any contact or garment problem holds realistic-motion promotion.

Each workcell tests a synthetic positive, adversarial false pass and invalid input without downloading source originals, copyrighted meshes, photos or identifying images. Source-only tests do not prove live MakeHuman geometry, visual likeness, anatomical realism or calibrated tissue. The existing real Blender contact RED in R084/R090 is binding, not overwritten by this unit-test PASS.
