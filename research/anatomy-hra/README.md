# Real HuBMAP lung donor → MPFB integration, R036

Rights and provenance: official HuBMAP CCF 3D Reference Object Library v1.2. HuBMAP specifies all CCF 3D reference objects under CC BY 4.0. Single 3D asset: `https://cdn.humanatlas.io/hra-releases/v1.2/models/VH_M_Lung.glb`, "3D Reference Organ for Lung, Male v1.2" DOI `10.48539/HBM787.FWXN.723`, creators Kristen Browne and Heidi Schlehlein. Official source description `hubmapconsortium/ccf-releases` `v1.2/markdown/ref-organs/lung-male.md`, plus https://hubmapconsortium.github.io/ccf/pages/ccf-3d-reference-library.html . The source revision and URL is version-identified but its SHA256 is unknown before first CI download; first run must record exact bytes and mark source admission PENDING, then pin observed SHA in follow-up before even a narrow source-custody qualification.

This independent stacked public-safe draft inherits the already qualified official MPFB HumanService 163-bone reference rig from draft PR #525. Download only the one openly licensed public lung GLB into an ephemeral public GitHub Actions runner with size cap. Use Blender glTF import to extract actual donor polygon meshes and provenance-tag them. Fit the *entire source organ ensemble uniformly* into a fixed **illustrative 0.30 m size** relative to `spine01` and attach donor geometry to the real rig; preserve subpart shapes and relative arrangements. Native animation, visible-source-only cutaway and external render, saved/reopened binding and source hash checks. This is a technical geometry/binding experiment, **not** anatomically registered organ location or medically correct size. It does not deliver lung tissue mechanics, respiratory dynamics or photorealism.

No donor mesh is committed to the public repo, public Actions artifact, logs or release. Credits and source fingerprints only. Do not pass personally identifiable private input through public CI. Unknown or prohibited source/asset terms remain STOP. Free Linux CPU GHA with finite job timeout; no commercial API or private runner.

Next experiment after source hash pin: spatial fiducial registration to native MakeHuman torso, left/right organ parts ontology and attachment to rib/diaphragm, deformable tissue constraints and independent visual contact validation. Three-audience UI/UX/DX/EX and engine reimport remain separate gates.
