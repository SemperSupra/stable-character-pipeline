# Continuous-delay acoustic proxy — draft, original synthetic-only research

Stacked on the **existing** atmospheric sound-speed and audible toy public PR [#557](https://github.com/SemperSupra/stable-character-pipeline/pull/557), under [environmental physics DLE #529](https://github.com/SemperSupra/stable-character-pipeline/issues/529) and the Physical Vocal owner DLE. The previously source-bound private v0 used `n=round(length_m × 48000 / 343)` integer sections, proven to yield bit-identical WAVs for `0.170m` vs `0.171m`, and it has no gas composition parameter. This new package is a **separate algorithm prototype**, never a replacement of the protected model.

A **fixed** first-order Thiran allpass provides fractional group delay at DC: `a=(1-d)/(1+d)` and `H(z)=(a+z^-1)/(1+a*z^-1)` for 0<d<1, preceded by an integer delay ring. At two-way travel `D=2 L F_s/c`, L may vary continuously between *separate offline renders*. Reflection feedback magnitude 0.65 yields a toy loss-bearing acoustic source-filter resonator. A deterministic sinusoidal/harmonic source and 48kHz PCM16 WAV can reveal sound changes for +1mm L or small c changes without the specific integer-cell dead zone. This is not the 9-section multi-scattering model, not pressure/volume conservation for humans, not full tract biomechanics, and **does not support live mid-stream parameter changes** (those need click-free state crossfades and a validated physical response).

Tests prove: identical input replay is bitwise stable, +1mm and small gas c shift alter WAV bytes, causal fractional-delay analytic allpass magnitude unity/pole stability for qualified factors, bounded impulse energy, nonfinite rejection and PCM headroom. Unit tests do not establish human auditory discrimination, spatially correct segmented formants, speaker identity, source reproducibility across Go compiler architectures or live latency.

From module `research/physical-medium`: `go test -race -count=1 ./... && go vet ./...`.
