The frame's volume flow `Q` is positive expiration, so `dV_lung/dt=-Q`. Elastic potential `U=(V-V_reference)^2/(2C)`; with prescribed branch flows the required external drive gauge is `P_drive = (sum_i R_i Q_i²)/Q - P_elastic_mid`, with units Pa; **this is not a measured subglottal pressure**. Midpoint integration conserves work: `P_drive Q Δt = sum_i R_i Q_i² Δt + ΔU`. Nasal and oral routes are hydraulic parallel branches: active branch pressure drops must agree. Closed/no-flow and non-pulmonary beatbox clicks consume zero bulk reservoir air. Oral/nasal/object flows use m³/s, volume m³, resistance Pa·s/m³, compliance m³/Pa, energies J. All numerical bounds are **computation admission** only, not medically safe/normal physiology.

Tests include full inhale/exhale volume recovery, signed energy balance, parallel nasal/oral pressure, zero-flow beatbox, straw inspiratory direction, invalid topology/NaN/negative volume rejection. `go test -race -count=1 ./...` and `go vet ./...` from module root.
