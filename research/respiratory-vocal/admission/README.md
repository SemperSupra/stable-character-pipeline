# Strict synthetic respiratory event ingress — research

An additive Go 1.23 stdlib-only admission boundary for [DLE #582](https://github.com/SemperSupra/stable-character-pipeline/issues/582), stacked on the existing source-neutral typed contract [draft PR #583](https://github.com/SemperSupra/stable-character-pipeline/pull/583). Recursively reject duplicate keys at every depth (including source items), missing/unknown typed event fields, trailing JSON, malformed UTF-8, oversized/nested input, malformed flow direction/route, nonfinite quantities and protected/nonpublic classification before use. Demonstrate deterministic replay and corpus-seeded fuzz regression. Does not change original respiratory audio source or private Physical Vocal's historic 21 PCM hashes.

**Not** a substitute for exact-byte payload SHA approval, asset rights/privacy review, a universal JSON Schema validator, or an inferred real person's medical or vocal state. All examples original synthetic and source-only, Go offline public Actions with no secrets/artifact upload, no private runners. Run `go test -race -count=1 ./...` and `go vet ./...` in `research/respiratory-vocal`. Preserve first failures and keep PR DRAFT/unmerged.

**Case-collision hardening (source-review correction):** strict `Decode` now walks the **exact canonical JSON tags** of all nested `Performance`, `Frame`, and `Source` structs before Go's case-insensitive typed decoder can alias fields such as `Schema` and `schema` or `Kind` and `kind`. This guards against semantically duplicate-but-differently-cased inputs, in addition to exact duplicate keys. A separate negative regression corpus documents the issue. The initial public tests passed before this finding, so preserve it as a **source-review discovery**, not as a claim of a failed hosted job.
