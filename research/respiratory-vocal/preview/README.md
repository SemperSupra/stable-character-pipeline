# Respiratory acoustic source palette — **synthetic preview only**

Independent additive source in [Respiratory performance DLE #582](https://github.com/SemperSupra/stable-character-pipeline/issues/582), stacked on the Go typed contracts PR #583. **No real recordings of people, no source-code donors imported, no LLM voice cloning and no physical human-respiratory calibration.** The original private Physical Vocal Go source and 21 historic waveform hashes are unchanged.

The bounded `preview.Render(behavior.Performance)` generates a deterministic original 48kHz mono PCM16 WAV from explicit typed events: signed inspiratory/expiratory branch flow, nasal low-passed synthetic turbulence vs mouth band-limited synthetic turbulence, pitched glottal harmonic proxy, an irregular voiced proxy, oral jet/lip whistle, flute/edge vs reed external tones, short non-pulmonary percussive clicks, and elastic-object airflow noise. It intentionally emits **silence when there is no airflow or active sound source**. These are *illustrative sound generators*, not sound-field physics, actual speech, matched voice identities, realistic continuous vocal-fold oscillation, or pressure/flow laboratory measurements.

**Public-safe fixtures**: nasal quiet breathing, oral quiet breathing, heavier oral breathing, alternating panting, humming, two sung notes, lip whistling, non-pulmonary beatbox clicks, edge-blown flute, reed instrument, external whistle, balloon airflow, straw suction, crying/sobbing proxy, laughter pulses, scream proxy, and zero-flow silence. The names are scenario descriptors; **no psychological diagnosis, injury, exhaustion level or airway safety inference is justified**.

Run `go test -race -count=1 ./... && go vet ./...` from `research/respiratory-vocal`. Create a new synthetic-only WAV directory: `go run ./cmd/performance-preview -out /tmp/respiration-original-wavs`. Each case has original SHA-256 and measured peak/RMS receipt. Positive/negative validation includes sample-clock, branch flow conservation and phase/port correctness, nonpulmonary beatbox with no lung-flow, close-to-zero exact silence, NaN/private asset refusal, output/clipping cap, deterministic replay and differences between quiet nasal/mouth/heavy/pant.

**Source-license/policy**: this is new original computational logic using only the Go stdlib; code/datasets from Faust, STK, VocalSound, Deeply SLR99 and others were *not copied or downloaded*; see `PRIOR_ART.md` for donor/source candidate review. Audio generated in public CI stays in ephemeral runner storage; only numeric/sha receipts in logs, no WAV upload and no secrets. No private GHA minutes. No merge/release/deployment.

**Future acceptance**: replace illustrative noise filters with validated nasal/oral branching acoustic geometry and breathing CFD reference, true timed pulmonary control and pressure consistency; use separately admitted acoustic jet/edge/reed, balloon membrane and straw impedance/contact models; integrate physical avatar movement, audio critics, source-to-intent human preferences and novice EN/DE/TH accessibility controls.
