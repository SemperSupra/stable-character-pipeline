# Paired body and bilateral material diagnostic

Independent source-safe sampled world-space observer for reference/candidate comparisons, not a gait generator. Exact 360@60Hz integer clock plus declared 1/32-frame dense windows. The input must identify both actors, fixed material vertices on each foot, root/pelvis/torso/knee/ankle markers and source scene SHA. Missing samples, duplicate keys, changed IDs, nonfinite coordinates and private/protected classifications are rejected. Report each side's maximum material displacement, induced and absolute speed, induced acceleration, ground minimum, root/body marker metrics and out-of-window effects. Velocity uses actual adjacent time intervals; acceleration uses midpoint spacing. These are sampled estimates, not analytic continuous extrema. Identity strings and scene hashes are caller claims until independently bound to native source custody. No support labels, pressure/GRF, anatomical thresholds, naturalness or acceptance are inferred.

Run `python3 -m unittest discover -s research/r009-paired-envelope -v`. Native workflow uses a real saved/reopened Blender original marker-and-quad fixture with a deliberate 30 mm root/contralateral shift and a left foot whose material is unchanged. This falsifies the inference that a stationary single foot proves full-body correctness. It is not MPFB, a rig, actual footwear, human movement or a protected scene. No binaries uploaded. Use the owning acceptance authority for any adaptation to private source; do not copy protected receipts onto public surfaces.
