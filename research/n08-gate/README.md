# N08 — typed revision-aware evidence transitions (public synthetic workcell)
This is a stand-alone, original Go standard-library falsifier of stale revisions, mismatched source/artifact SHA, unknown transitions, forged receipts, duplicate JSON keys, noncanonical technical PASS and concurrent CAS conflicts. It is **not** a production replacement for existing private R009 scene CAS, rights audit or source-custody logic; no real-owner grant, release, protected source, sovereign host or paid minutes.
The only operations are `PIN_SOURCE`, `DERIVE`, `BIND_RECEIPT`, `HOLD`. All are version-bound and lock-serialized. `BIND_RECEIPT` means a *synthetic technical receipt is bound to bytes*, never that the receipt is externally independently authenticated or that the product is approved.
`OWNER_ACCEPT` and `RELEASE` unconditionally refuse. No on-disk atomicity/cross-process CAS is claimed. Private R009 PR #126 already implements scene-file CAS and is untouched. This Go experiment tests an independent in-memory reference for DLE composition rather than duplicating or replacing it.
Run `go test -race -count=1 ./...` and `go vet ./...` in this module. Public standard Ubuntu and Windows GHA jobs are limited to 6 minutes, source-safe JSON only; reviewer must compare exact-head logs, negative tests and receipt SHA. All acceptance gates remain HOLD.
