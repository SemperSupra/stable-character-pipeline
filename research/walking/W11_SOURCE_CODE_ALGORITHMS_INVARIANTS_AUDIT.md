## Concrete failures / negative space found by reading source

1. **Contact-pass ≠ dynamic continuity.** W06/W08 validates zero displacement only on adjacent frames with BOTH contact flags true. It does not gate initial touchdown, final liftoff, velocity/acceleration of hands/hips at phase changes, or cancellation of swing at stop. W08 sets `contact=True` beyond 5.4s using a 5.4−ε sample even if the prior frame was swinging. Add exact transition-side limits and counterexamples; do NOT weaken current stance checks.
2. **Native shoe ≠ physical contact.** W10 evaluates mesh world-foot Y correctly, but permits sole Y between −0.005 and +0.032; observed static sole about +0.015 scene units. This is a **thresholded proxy**, not force equilibrium or actual zero-gap mechanical contact.
3. **Rigged polygons are not skinned anatomical humans.** W06/W09 scene uses separately keyed primitive object parts, no continuous deforming vertex skin. Must compose the proven W05/NASA weighted-skin native readers and a 3D hierarchy before transferring claims.
4. **Normalization / format mismatch.** Blender quaternion uses WXYZ in mathutils and MMD/glTF channels XYZW. MMD VMD authoring uses signed cp932 names and 127-based Bezier control points; MMD quaternion slerp interpolation semantics differ from Blender importer as acknowledged in upstream source. Do not claim VMD→GLB observational equivalence without resampling residuals.
5. **Topology fallback is unsafe for our contract.** Godot’s out-of-range/missing bind logs error and assigns bone index zero to continue rendering. Our admission contract must reject instead; failure should be source-visible with exact bone name.
6. **Performance primitive not architecture mandate.** Ozz SoA jobs and Godot nested dirty subtree are proven implementation structures for high-volume/real-time animation, not an argument to adopt native C++ into current Go/Python public-GHA baseline before qualification. Preserve Go deployable core and use upstream code as independent executable oracle where license/toolchain allow.
7. **Source data ≠ model identity.** MMD importer named-bone matching can transfer animation to a topology with matching names; it does not preserve face/body identity, proportions, full contact, private appearance, or consent/rights of third-party assets. Asset manifest remains mandatory.

## Proposed compositional architecture (no owner acceptance assumed)

```text
[Rights-clean original motion | MMD VMD/PMX | BVH/FBX/glTF adapters]
     -> immutable source packet (SHA, rights, explicit local time + source axis/units)
     -> canonical source motion: actor IDs + skeletal topology/rest frame
           + local Quaternion XYZW / root XYZ + contact event spans
           + optional hip/ankle world constraints; preserve raw source observations
     -> policy-/admission-controlled target rig map (joint semantic ID, rest offset, scale)
     -> candidate solvers [2-bone analytic with pole+soften | CCD long chain]
     -> model-space FK, joint limits, event-bound contact correction and pose blending
     -> target skinned mesh [LBS required GLB interchange; native DQ variant explicit]
     -> native Blender .blend + animated GLB/MP4 and *independent* pure glTF numeric reader
     -> indexed vertex world parity + true 3D sole/contact/visibility acceptance
     -> owner acceptance of public candidate; private original MVP separately gated
```

**Common structure proposal (new version, not silently retrofit W06):** `scp.motion.canonical.v2` with `source{sha256,license,rights,producer,coordinate_basis,units,frame_origin,rational_fps}`, `actors[{id,rig_id,root_xyz,joints[{semantic_id,parent,rest_local_mat4,local_quat_xyzw,local_xyz,limits}],contact_events[{foot,start_ns,end_ns,anchor_world_xyz,surface,certainty}]}]`, `frames[{timestamp_ns,pose_values}]` and optional provenance-separated qualitative style/culture metadata. Contact derived/annotated separately from raw source and no inference of real-group identity. Rig-dependent dynamic arrays should compile to stable indexed SoA/packed vertex buffers, with a human-readable map and generator/consumer validation.
