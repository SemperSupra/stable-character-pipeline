# R036 native MPFB macro morph and anatomy-binding probe

An independent stacked test (base draft #525 exact head `e75bd3b025841cb5aca845cb20278b68a476392a`) using **the official MPFB HumanService/TargetService/HumanObjectProperties services** in an installed native Blender extension. It starts from the already source-pinned, rendered/reopened official MakeHuman character and tests original phenotype plus two different height/weight macro states. Calls actual MPFB `TargetService.reapply_macro_details()` and `HumanService.refit()` on the same native skinned character, without modifying the parent workcell. Evaluates actual external mesh geometry, official bone rest positions and synthetic attached-proxy centroids/normalized offsets, topology invariant, native save/reopen. Emits machine-readable measured deltas.

**Important:** Two ellipsoids in the parent fixture are diagnostic deformable structures, not positioned real lungs or anatomical medical truth. An attachment is not automatically correctly *registered* when the character changes height/weight. This probe deliberately quantifies shifts and reports anatomical registration `HOLD`, even on successful geometry tests. Do not silence drift or promote numerical thresholds without qualified anatomical reference.
