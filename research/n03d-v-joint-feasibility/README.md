# N03D-V — bounded convex joint root/foot temporal surrogate feasibility

N03D-U native source-relative ankle IK moves the target head closer by ~35mm but **actual CC0 shoes** still hover/penetrate. Previous N03D-J found 0 observed planted stance intervals, N03D-H measured true persistent shoe-material sliding, and N03D-F3 found only short proxy windows are geometrically close to fixed support. This workcell does **not** invent stance labels or authorize motion adoption.

Implement and independently test an actual coupled least-squares temporal correction **surrogate** on measured source-authorized 24Hz deformed CC0 shoe-support patch centroids. For each 4×24Hz-sample window (starts24/48/72/96) both shoe rest-local-X partitions have hypothetical planar anchors at window start and z=0. Optimize root translation r[t] shared between both sides and separate per-foot translations f[side,t] with contact penalty, root/foot magnitude regularizers and temporal first-difference smoothness. Convex smooth quadratic with Euclidean-ball constraints root and each foot <=40mm at each frame, deterministic backtracked projected gradient 320 iterations, explicit energy nonincrease proof and actual residual/penetration/hover before/after under a **linearized translation surrogate only**. Three independent model classes root_only, foot_only, joint, same objective/data. Lack of full IK or plantar mesh actuator means these numerical residuals are not native verified contact and cannot pass physics or MVP.

Evidence comes from exact source-pinned original-fictional Aster/Juniper 163-bone MPFB, six real CC0 garments and CC-BY-4.0 100STYLE source retarget (R090) in official Blender 5.2.4 LTS; existing source trace D is 143 evaluated 24Hz points per shoe partition, exact native source SHA, original means no protected Naomi/Alison.
