# R036 independent ICP challenger for HRA-to-MPFB coarse registration

Stacked exactly on source-locked HRA skin/lung registration draft PR #560, starting commit `1dba844f0119cc944a903c3921d33fc6ad71ed7f`. This is **not** landmark registration: it tests the first bounded proper-hand rigid refinement using real HRA source skin 92,659 vertices and actual MPFB evaluated skin, with existing HRA 67 source-lung meshes following the same transform. All donor bytes, rights and exact SHA checks are inherited from the parent; no license or artifact transferred to public Git.

The initial coarse best surface matching from #560 gives HRA→MPFB 95th percentile approximately 97.8 mm (still poor) and cannot disambiguate left vs right. This challenger uses approximately 2–3k deterministic sampled vertices, iterative nearest-point lookup, 72%-trimmed Kabsch fit, 12 CPU iterations maximum, fixed source height scale, positive determinant and at most 25° rotation from original orientation. It retains whichever actual measured candidate has the smallest declared combined nearest-neighbor p95 score; it cannot declare success just because ICP iterations ran. The independent unit control requires recovery of an original rigid transform and rejection of a mirror as a valid rotation; no correspondence/measure is considered an anatomical landmark. Records **six vertical body-region residual bands** and the before/after errors so large mismatches stay legible.

**Acceptance boundary:** source-geometry ICP can refine a surface match but cannot certify human organ placement, laterality, front/back, lungs inside pleura/ribs, clinical truth, tissue mechanics, or photorealism. A real anatomically correct system must use independently reviewed lateralized fiducials (sternal notch, clavicular heads, iliac crests, sacrum, T1/T12, lung hila, diaphragm dome and rib surfaces) and anatomical containment/collision oracles. Source models may be anatomically distinct people. The result must remain `NOT_ADMITTED` even at tiny residual.

Actual free-tier Ubuntu CPU Blender+NumPy test in a draft stacked PR, no protected identities, no private GHA or media uploads, no merges/releases/deployments. Report exact source SHA and first RED to DLE #175, parent #174. Fully reproducible original synthetic unit control inside the same script.
