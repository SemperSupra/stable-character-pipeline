**Official original publisher landing page:** https://mocap.cs.cmu.edu/subjects/07/ ; indexed pair 07.asf plus 07_01.amc and 07_02.amc, corresponding to separate WALK trials. Publisher source terms at https://mocap.cs.cmu.edu/ and https://mocap.cs.cmu.edu/faqs.php allow copying/modifying/redistributing motion captures but forbid **direct sale of raw/converted capture data**; no exclusive license is assumed. The source FAQ gives original coordinate→meters factor (1/0.45)*2.54/100, but source contents/units/calibration and 120Hz timebase must be verified against original bytes. The official publisher warns toe/hand joints can be noisy and finger/thumb motion is not measured.

**Executed experiment shape:** Two independent public, standard/free GitHub Actions Ubuntu runners each fetch only the original official subject 07 ASF and one indexed trial AMC over **verified HTTPS**. No database crawl, mirrors, HTTP bypass or insecure TLS switches. Pure Python stdlib parser checks genuine ASCII ASF skeleton hierarchy, source frame numbering, finite channel values, source joint count/compatibility, unique measured root 3D channel and derived source root duration/displacement, and hashes exact source bytes. Deliberate corrupted source tests execute before any remote retrieval. External raw files stay only in disposable runner TEMP; public Actions artifact contains **JSON source metadata plus original-byte hashes only**, not ASF/AMC recordings, recordings of people, or converted resalable motion.

**Admission state:** Source publisher terms reviewed but exact processing, redistribution and user-private production adoption remain separately controlled by R012 private #35, R014 private #138 and R009 private #23. Even two green source-metadata jobs do **not** establish source skeleton FK/coordinate transforms, ground-truth physical foot pressure, source/target cross-identity motion, working Blender retarget, natural gait or a photoreal human. No training or production use from source-only metadata. Strict fail-closed if official HTTPS certificate is invalid or source shape fails its constraints. Preserve all failed acquisition receipts.
