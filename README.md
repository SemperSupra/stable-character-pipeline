# Stable Character Pipeline — public source-safe research

The default `main` branch is a minimal bootstrap. Active Blender/MakeHuman, source motion, geometry and critic experiments are isolated in **draft research PRs** with exact tested commits. Their source code may not exist on `main`; inspect live PR heads before assuming a capability is absent.

**Fresh human / agent start:** [AGENTS.md](AGENTS.md) points to the [adopted Way of Working](https://github.com/SemperSupra/engineering-governance-private/blob/main/WAY_OF_WORKING.md), [private owning R009 DLE #23](https://github.com/SemperSupra/stable-character-pipeline-private/issues/23), and its [parallel batch baton](https://github.com/SemperSupra/stable-character-pipeline-private/issues/23#issuecomment-7072561186). No prior chat or pasted briefing needed. Public [physical #662](https://github.com/SemperSupra/stable-character-pipeline/issues/662) and [numeric #650](https://github.com/SemperSupra/stable-character-pipeline/issues/650) DLEs retain experiments and exact source/evidence.

**Deterministic automation:** [four-lane source-critic free-tier CI](.github/workflows/r009-four-lane-free-rep.yml) independently checks four immutable prior workcell heads in parallel on free public GitHub Actions. It only checks source-bound *critics*, not Blender physical-gait acceptance. Actual native Blender proof lives in the corresponding workcell Actions runs, not this bootstrap.

**Protected acceptance:** The real two-person park H.264 product, identity assets, rights, native body+foot motion, wardrobe/soft tissue, ground support and three-audience acceptance are under private owner control. No public CI upload of protected character media. Passing tests in this repository does not grant publication, release or MVP acceptance.
