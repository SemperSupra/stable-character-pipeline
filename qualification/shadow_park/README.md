# Public original-authored two-character shadow production (surrogate MVP)

This is an independently scoped, intentionally non-promoting **synthetic shadow** of the private R009 park-walk acceptance shape. Its source is newly authored procedural geometry and motion **only**. It does not use, copy, infer, train upon, transform or publish Naomi/Alison original likenesses, photographic files, private rigs, measured captures, family identities, original performer movement or protected Google Drive assets.

## Why

Rather than waiting for protected source custody and runner approval to test the pipeline, reproduce the expensive/fragile **engineering** conditions in the public domain:

- Two visually distinct original surrogate actors, facing each other, approaching along a path, slowing to a stop, frame clock **72 at 12 fps / 6-second playback duration**
- Each actor has **13 articulated geometric bone segments**, direct pose keys and Blender `ARMATURE` deformed proxy meshes (26 distinct modifiers, not merely rigid scene-root translation)
- Foot-plant and swing pseudo-ground truth: explicit two-link planar IK, source bone lengths, foot sole clearances, 72-frame stance masks, static ground-contact coordinates and swing lift; *synthetic engineering constraints* not independent human biomechanical truth
- Two separately authored camera extrinsics, 72-frame **real Blender Workbench** PNG sequences each, native FFmpeg H264/12fps/iPhone-compatible yuv420p clips and one 6-tile image contact sheet
- Pre-render GitHub Actions **eight-job parallel matrix**: correct baseline plus sliding contact, joint-length/hyperextension, root-only freeze, swapped camera roles, illegitimate human admission, duplicate actor alias, wrong source clock. Each hostile input MUST fail source-independent QA; video render only if all eight qualify.
- Source SHA256/metadata typed receipt, frame-bound artifact hashes, independent FFprobe decoded H264 frame counts and camera-video non-alias checks
- Public standard `ubuntu-24.04` GitHub runners; no paid larger runners, no private GHA minute consumption, transient official SHA-verified Blender 4.5.15, no external model or dataset downloads.

## Deliberately unproved

- The rigs are **unparented bone controls** whose pose keys follow an authored two-link planar IK oracle; they are NOT a hierarchical anatomical skeleton or independently exercised IK solver.
- Mesh proxies are 100%-weighted rigid skinned cylinders, NOT full-body human surfaces, LBS blend deformation quality, cloth/hair/eye fidelity, or true foot soles.
- Contact, knee-ROM and gait are engineered self-authored patterns, NOT source-measured or independent human/animal physiological norms.
- Camera bytes and recorded 3D source are not a trusted cryptographic independent camera issuer. No real hardware/source custody or independent visual human inspection.
- No actual original CMU 18_01/19_01 ASF/AMC, Cologne capture, private Naomi/Alison, CPE blind, rights approval, protected private runner, authenticated producer rig receipt, clean true 72f/6s original two-person video or release acceptance.
- `private_r009:HELD_NOT_ACCEPTED` is enforced through source, test and metadata. No automatic promotion, merge, release, deployment or source licensing shortcut.

## Three audiences / DLE / artifact custody

Humans: inspect both H264 clips, original scene contact sheet, viewer README and adverse run logs. Automation: deterministic `produce.py` JSON, `review.py` structured rejection reasons, exact GitHub CI run + native/video receipt checks. Agents: `produce.py --capabilities` is read-only action discovery, no protected-data or release authority; runner/rights classes stay explicit.

Scientific and product statuses are independent from CI engineering success. Source code and small evidence/index hashes live in public Git and the public motion DLE; large *original-authored* binaries may be uploaded into owner-private Google Drive using the AAR/CDR full-byte readback pattern, never private original assets to public GHA. CI raw media retention 2 days; persist larger media only after independently observing and hashing the exact run.

The next rung should parameterize seeds, camera lens/obstruction, limb proportions, joint-angle perturbations, gait clock timing and contact surfaces, then run independent multi-view QA, inverse retargeting and source→corrected VMD→Blender crosswalk. It is not a replacement for actual R009 rights/custody and original identity-bearing protected executor.
