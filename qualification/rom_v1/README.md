# ROM V1 — bounded source-only joint kinematic envelope

Authority [ROM DLE #170](https://github.com/SemperSupra/stable-character-pipeline/issues/170), related walking #84, VisualQA #150. This is an original-source Go-stdlib *numeric* validator. It is **not** a biological movement certifier or robotics safety controller. Source rights are the original synthetic-only allowlist. No private character assets or external dependencies.

Input `scp.rom.v1_input`: original source SHA256, rights, morphology kind, context, exact rational source clock, list of named joint DOF contract entries, frames with actual observed position and optional effort, plus optional linear source-only master/slave coupling. Each scalar joint supplies units, local coordinate frame, provenance, hard limits, optional soft bounds, maximum velocity, acceleration and jerk; effort if available. Current accepted fixture frame `PARENT_LOCAL_TEST_ONLY` and authority `SYNTHETIC_TEST_ONLY` are **numerical unit tests only**. Biological species and robot model kinds return **UNKNOWN** until independently qualified anatomical/mechanism source/real observations exist.

Algorithm: verify exact source bytes SHA, clock monotonicity and joint sample coverage; scalar hard bounds -> FAIL, soft margins -> WARN; exact rational tick durations -> finite-difference speed/acceleration/jerk bounds and coupled-DOF checks; missing provenance, torque and dynamic evidence -> UNKNOWN. Continuous-revolute wrap is deliberately UNKNOWN without an approved unwrapping oracle. Output `FAIL`, `UNKNOWN`, or `PASS_SYNTHETIC_SCALAR_LIMITS_ONLY` with first tick/joint reason. A green test NEVER clears VisualQA original pixel freeze FAIL, mesh contact, dynamic equilibrium, species-specific ROM or product holds.

Negative tests: hard-stop beyond bound, high-speed but within angle bound, acceleration, jerk, wrong mirrored coupling, source SHA/rights/clock/joint missing, unqualified human/animal/machine model, missing effort and nonfinite coordinate. 0 exit only on permitted fictional synthetic scalar envelope; 2 hard reject, 3 UNKNOWN. Do not rely on this output for injury prevention or hardware control.
