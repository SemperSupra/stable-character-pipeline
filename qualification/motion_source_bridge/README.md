# Source-only motion/score evidence bridge

Cross-validates the existing public C1 first-pass *Morris Book* Cross-over source witness and the separate synthetic C5 score time-map **without** asserting that their actor roles, movements or music match. Output is always NOT_ADMITTED: a successfully checked JSON metadata pair is not measured motion, accepted historical notation, independent second-reader gold, or R009 identity/rights/rig acceptance.

From this folder: `go test -count=1 ./...`, `go test -race -count=1 ./...`, `go vet ./...`, then `go run . -figure c1.json -score c5.json` or `go run . -capabilities`. The source text/diagrams, MIDI or WAV are **not** read; input receipt hashes are not an independent origin attestation. This detects forged claims, status promotion, invalid source edition, duplicate keys, and rational seconds-to-sample mismatches only, not beat-to-physical-motion alignment. Two inputs each <=1 MiB. Public-only; Git/DLE stores source and receipts, private Drive only for admitted large artifacts.

Follow public motion DLE #19 and shared index #29, private human R012 #35 and R009 #23, and CPE blind hold. No private identities or data, public protected runner, merge, release, deployment, dataset admission or semantic promotion.
