# W4B research provenance gates

Evidence references and independent source bytes SHA are required; a title or abstract cannot authorize an anatomical ROM numeric table. Enforce exact species, joint parent/child, anatomical JCS context, units, mode (active/passive/model), source rights, cohort, independent review status and optional bounded numeric candidate. All human/animal/machine candidate values remain UNKNOWN until separately source-authorized review; negative review FAIL. No real-human data or protected private rig in public CI. Git/DLE source and receipt; no large binary produced.
