# Read-only exact-input evidence reuse qualification (experimental)

Owner: public R009 housekeeping DLE #272, source #312; cross-species experiments #293. No new service, database, branch authority, merge/close/delete operation, required-CI waiver, private source access, or change to the existing GET-only auditor.

This is a **diagnostic library**, not an activated cache. `ExactInputFingerprint` canonicalizes the complete verified input closure: source, workflow, runtime/toolchain, synthetic fixture, rights classification, plus optional observer/tool inputs. IDs are bounded and SHA256 digests must be lowercase/valid. Missing and duplicate entries are rejected. A changed dependency yields a different fingerprint.

`EvaluateTechnicalEvidenceReuse` returns `RUN_REQUIRED` unless the exact fingerprint matches an independently provider-checked successful run with an accessible unexpired artifact, verified trust boundary and no source scope drift. Its only positive response is `REVIEW_EXACT_TECHNICAL_EVIDENCE_REUSE`, **never PASS, SKIP, MERGE or RELEASE**. All fields in `FingerprintProof` are still supplied by the caller; this library *does not perform or attest remote provider verification*. Treat `VerifiedBy` as an input claim until a separate authoritative reader implements actual readback.

The problem: GitHub PR path filters examine the cumulative diff against the base, so repeated child commits retrigger old unrelated workcells even when their input closure is unchanged. This primitive helps quantify candidate reuse safely, **but produces no runner-minute savings until** a separately authorized exact-run source-of-truth verification, CI required-check policy, artifact custody, branch protection and no-loss fallback are tested. Missing/expired/failed/mismatched evidence always requires a fresh run. Scientific FAIL may be valid technical evidence but cannot become an accepted scientific result via cache reuse. Never use a PR author-controlled receipt alone to suppress mandatory checks.

Local reproducible tests: `cd qualification/repo_hygiene && go test -race -count=1 ./... && go vet ./...`. Benchmarks: `go test -run '^$' -bench 'Benchmark(ExactInputFingerprint|TechnicalProofReuseReview)$' -benchmem ./...`; local timing is diagnostic only and cannot be compared across runners without equivalent hardware/toolchain.
