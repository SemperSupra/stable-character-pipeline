# W6-B5B native six-bone rest verification

The live W5D C4 source actual native 24-frame weighted skin was already qualified in research PR #185. This independent scope checks each of 12 source-original rest bones on two six-bone rigs with actual Blender matrix_local, parent-relative matrices, head/tail, original heel/toe foot-bone forward-Y axis, exact rights and C4 source SHA. Third pure stdlib 4x4 matrix oracle checks each actual hierarchy without importing bpy. Native rest mapping is not anatomical JCS, loaded ROM, true biomechanical knee direction, texture, force, multi-view pixels, or real private characters. One source-defined plane and one synthetic clock only. Exact actor and original source identities are scoped to this test. Public free runner, draft only. Git/DLE stores source and small evidence; private owner Drive stores large generated media when created.
