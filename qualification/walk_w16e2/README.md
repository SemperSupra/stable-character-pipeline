This wholly original 2-second marker test creates 24 synthetic motion IDs at 12fps, duplicates each as 48 real FFV1 24fps RGB frames, and produces original mono PCM16 48000Hz sound clicks at exact 4000-sample motion boundaries. The baseline parent workcell muxed Matroska, which quantized video PTS to 1 ms and produced an observed native PTS error of 333.333 microseconds against an unchanged <=0.5 microsecond source-clock gate (GHA 41095475028 RED). This corrective child uses actual NUT/FFV1+PCM16 and checks each native integer frame tick with the declared rational stream time base against exact frame_index/24. A separate local A/B experiment verified NUT at 0.333 microseconds maximum printed-decimal time error while Matroska remained RED, without relaxing the gate. A separate fresh ffmpeg consumer independently decodes every RGB frame and every audio sample to source bytes and uses exact rational native integer time ticks plus Decimal to verify all 48 observed ffprobe PTS against i/24, tolerance <=0.5 microseconds, no source motion freeze. This only qualifies this source marker, not C3 Blender video, real spatial #39 speech, lip sync, or private R009.
