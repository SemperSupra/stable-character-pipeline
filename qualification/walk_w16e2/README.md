# W16-E2 observed native decoded A/V clock

This wholly original 2-second marker test creates 24 synthetic motion IDs at 12fps, duplicates each as 48 real FFV1 24fps RGB frames, and produces original mono PCM16 48000Hz sound clicks at exact 4000-sample motion boundaries. It muxes actual Matroska in a standard public Ubuntu free runner. A separate fresh ffmpeg consumer independently decodes every RGB frame and every audio sample to source bytes and uses Decimal to verify 48 real ffprobe PTS positions against exact i/24, tolerance <=0.5 microseconds, no source motion freeze. This only qualifies this source marker, not C3 Blender video, real spatial #39 speech, lip sync, or private R009.
