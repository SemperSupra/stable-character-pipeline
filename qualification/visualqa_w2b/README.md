# Visual QA W2B — image-to-projected-weighted-geometry observability

Authority [DLE #150](https://github.com/SemperSupra/stable-character-pipeline/issues/150). Research-only, stacked on original public VisualQA V1 PR #152 exact starting commit `cb8de12d929ed5e118b1fef0d835132ecf6deb2c`.

The **independent** source Blender adapter reopens the saved source-original .blend, reads the actual orthographic scene camera and 112 evaluated, weighted mesh vertices at seven source frames (784 vertex observations), and provides both world coordinates and Blender-native screen projections. A separate stdlib observer independently computes camera projection from explicit numeric camera matrices, compares every native 2D projection with this alternative arithmetic witness, *decodes the actual H264 grayscale pixels* and checks where projected source mesh vertices land relative to foreground. It reports coverage/bounds and abstains on missing pixels. Intentionally broken camera projection, black-video, wrong-source SHA and genuine encoded gray-video controls are executable tests.

A correctly projected vertex or visible gray pixel does **NOT** prove skin fidelity, physical contact, correct knees, full human geometry or identity. The independent camera parity check may fail from an unqualified Blender camera convention; preserve first numerical mismatch rather than relaxing bounds. One view cannot adjudicate 3D anatomy. W2B output can only be `OBSERVED_UNQUALIFIED` or `UNKNOWN_MISSING_FOREGROUND` unless the numerical camera contract fails, in which case the job fails. Existing L1 freeze veto from PR #152 remains unchanged and continues to reject the two original videos.

Standard public free GitHub Actions CPU only, two synthetic-profile jobs in parallel and a separate source-negative control job. No private character/rights-unknown source, API subscription, paid runner, merge/release/deploy or CPE promotion. Git/draft PR and DLE own source, tests and receipts; large output remains ephemeral unless the original complete bytes are captured and verified in owner-private Google Drive.
