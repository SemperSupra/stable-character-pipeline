# W3c shared-reference off-axis/elevation/listener-yaw DOE (preflight only)

Authoritative [Spatial W3 issue #39](https://github.com/SemperSupra/stable-character-pipeline/issues/39) and [Spatial DLE #18](https://github.com/SemperSupra/stable-character-pipeline/issues/18). This draft builds only **the common first-party Go scene input matrix**, not yet measured EBU vs VideoLAN audio. Research-only $0 public GHA, originally authored synthetic geometry, no private final voices/paid runners, no merge/release/deploy.

**Experimental axes:** 7 source azimuths (0, ±45, ±70, 120, 180), 2 elevations (0 and +30), and 3 listener yaw orientations (0, 90, 180), at fixed listener/source distance 10 m and 48k source clock. Total **42 unique cases**. The same target layout list on each case is 5.1 and 7.1; generated in the canonical right-handed ENU world coordinate conventions with a translated listener origin, then independently recovered via the existing `spatial_audio.v1` Go `PoseAtFrame` calculation. Angular direction and distance comparisons and translation-invariant negative tests are exact (floating-point tolerance). Every case preserves both provider statuses **NOT_MEASURED** until actual native C++ library and PCM experiments run. Pin VideoLAN `d149ed9744fd399b835c6f2920511f8cbcfce5ea` and EBU libear `2db69f8fcea0bc5db8a78e14a9c2ae6ed4283c15` separately.

Operator/agent command from spatial-contract module root: `go run ./cmd/spatial-doe plan > matrix.json`. Creator can inspect source positions, yaw, azimuth, elevation and profile for each proposed case. Operators can dispatch/budget/replay cases without guessing coordinates, while agent/developer interface uses Go `doe.Generate()` and JSON `spatial_audio.offaxis_doe.v1`. There is no GUI sound-stage yet.

Do NOT claim a matching channel-gain ratio validates actual positional listening or headphone/binaural localization. Native direct stereo remains NaN-quarantined. Use original clean fixtures, no copyrighted recordings or unlicensed HRTFs.
