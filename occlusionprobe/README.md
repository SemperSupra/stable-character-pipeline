# R075 — Real Cycles 3-D occlusion must cause typed semantic-tracking abstention

Authority: private [R037 #176](https://github.com/SemperSupra/stable-character-pipeline-private/issues/176), visual critic [#168](https://github.com/SemperSupra/stable-character-pipeline-private/issues/168), film MVP [#23](https://github.com/SemperSupra/stable-character-pipeline-private/issues/23). Exact frozen parent public [R073 #626](https://github.com/SemperSupra/stable-character-pipeline/pull/626) HEAD `31aac75610c2f34979cea07d7348be704394978c`. New independent `occlusionprobe/` and one free public CPU workflow only; no change to R073 source.

**Experiment:** One original synthetic stylized head, 13 source head meshes with pass index 3; stationary head and fixed 65 mm perspective camera. A separate original procedural camera-facing solid foreground occluder with pass index 4 is positioned in true 3-D from the camera's native world matrix at 65% of head depth. Predeclare three configurations **clear** (off-camera), **partial** (0.56×0.78 scene-unit solid offset in the camera plane), and **severe** (2.4×2.3 solid centered on head), with unique source mesh digests. Capture actual 256×256 Cycles PNG+multilayer EXR in each state, source-native raycasts, independent official OpenEXR3.3.3 camera-axis Z and per-pixel object segmentation and file SHA.

**Acceptance falsifier, not photorealism:** Actual clear head EXR index3 area must exceed 500 pixels with no foreground index4 pixels; partial index3 area fraction 25–93% of clear with >200 actual index4 pixels, severe <=20% of original head visibility with >1000 index4 pixels. All raywise Z/ID comparisons retain R057 predeclared >=98% correct/<=0.05 scene-unit axial depth and >=64 native stable samples. Each case source 3D occluder parameters, camera, head/occluder indices, source scene SHA, file SHA, no nonfinite or malformed ray coordinate passes guarded. The only acceptable disposition under partial/severe occlusion is the typed `HOLD_PARTIAL_OCCLUSION_NO_PERSON_ID` / `HOLD_SEVERE_OCCLUSION_NO_PERSON_ID`; **not** continuing to guess a human identity, gait, source correspondence, silhouette trajectory or owner preference. Source fixtures deliberately forge rights/camera/depth/source object IDs, missing/head masks, reversed visibility and severe mislabeled as partial to require HOLD.

**Reproduce:** Disposable original-only Blender 3D source `blender -b -t 2 --python occlusionprobe/scene.py -- --out out`; pinned NumPy+OpenEXR venv `python -m unittest discover -s occlusionprobe -p test_audit.py -v` then `python occlusionprobe/audit.py --root out --out out/r075_report.json`. Workflow `.github/workflows/r075-exr-occlusion.yml` is free public Ubuntu CPU, 20min hard timeout, strict independent file digest verification and 3-day public original-synthetic artifact retention, no private CI, pretrained/paid weights, real identity, third-party asset or private source.

**Scientific limit:** A `PASS_NARROW_REAL_EXR_OCCLUSION_REQUIRES_TYPED_HOLD` qualifies only a source-known original fixture and deliberately fail-closed source/EXR semantic visibility under three 3-D foreground occluder regimes. It does not prove 6-DoF tracking under real occlusion, optical flow, lost/reacquired identity, general VLM, human anatomy/gait, user taste, source license, native MakeHuman or the Naomi/Alison H.264 park MVP. Draft and unmerged until separate source-proven product acceptance.
