# R0b independently issued release evidence (source-safe draft)

**Corrects a real acceptance gap:** R0's manifest verifies only JSON shape, PASS labels and digest syntax. A caller could construct all nine PASS labels with invented hex values. The original R0 remains a structural check. This **additional independent verifier** insists on *actual bytes* and cryptographically verified **Ed25519 signatures** from an external, explicit gate-specific trust policy before it reports verified signed evidence. It does not execute a release or infer real human/biomechanical/rights validity.

- Exact source dependency: public R0 draft [#206](https://github.com/SemperSupra/stable-character-pipeline/pull/206) `c6bf60a31c4a4e982478d980a6a0aebeff52c3a9` unmodified.
- `releaseproof verify MANIFEST.json TRUST.json PROOFS_DIR EVIDENCE_DIR`: release manifest requires candidate/released and all nine PASS receipts. For gate `G`, `PROOFS_DIR/G.json` must hash to the original manifest `receipt_sha`; immutable source/image/scope/evidence hash/issuer/gate are bound into a signer-specific message; `EVIDENCE_DIR/G.bin` must exist as **a real non-symlink regular file** and match the independently signed evidence SHA. All JSON rejects duplicates, unknown properties, trailing data and oversize. Invalid proof/signature, changed byte, missing trust, wrong source or alias fails.
- `TRUST.json` is never provided from an untrusted manifest or public fixture in production. Trusted public keys and exact gate-issuer assignments must be admitted separately by a review authority. The behavior, security, custody, and deployment signers must be distinct from each other and from the build signer. Public tests generate **synthetic test-only Ed25519 keys** dynamically for the checks and cannot confer production owner authority.
- Signed evidence proves that an assigned key signed given evidence bytes, **not that the issuer was competent, the biology is valid, the licenses clear, or release approval exists**. It does not bind a chain of materials beyond source SHA and image digest; additional independent provenance, scientific peer review, actual authenticated private custody, signed runner/identity policy, and explicit owner release approval are still required. No signer private key, person linked media, token or private infrastructure is committed.
- Run: `cd releaseproof && go test -race -count=1 ./... && go vet ./...`. Standard $0 public GHA only. Current R009 original human rig/custody, canonical R007, private-runner, merge and deployment holds remain.
