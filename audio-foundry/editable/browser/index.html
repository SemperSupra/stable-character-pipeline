Audio Foundry — editable source

Open an editable_audio.v1 JSON project, change underlying music notes or procedural motor parameters, and export a new revision. This editor runs in your browser without network calls. WAV/M4A playback is separate; a changed source must be re-rendered with the Go and Csound tools.

Select a public synthetic source project to begin. Private final-character data must not be used with this public editor.
