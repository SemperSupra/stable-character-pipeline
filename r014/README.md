# R014 alternate Blender Studio realistic human sculpt foundations

This independent $0 public-runner research lane sources the publisher-hosted **Human Base Meshes Bundle v1.4.1**, 50,643,039 bytes, officially published January 20, 2026. Blender's own source metadata documents the realistic male and female base meshes under **CC0**. This differs from the separate *Project Heist* earlier base (CC BY), which is NOT included.

This batch inventories library objects and appends only named realistic male/female sculpt bodies to an editable native Blender research scene. It records polygon count, UVs, multires modifiers and rigging status. A first observed SHA-256 must be recorded and later pinned/verified before promotion. It never imports a private human likeness or mixes CC BY anatomical models.

**HOLD:** realistic sculpt topology is not the same thing as a full parametric human/soft-tissue character. External genitalia may be missing; anatomy, hand articulation, rig, facial expression controls, skin optics, hair, multires and actual rendered video require independent follow-up. Do not claim anatomical completeness or photorealism from a base mesh.
