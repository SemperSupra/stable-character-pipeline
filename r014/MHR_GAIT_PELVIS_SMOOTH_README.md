**New independent variation:** Compute minimum pelvis lowering for both legs at every original frame, then calculate the mathematically minimal nonnegative slope-limited upper envelope of those exact requirements, limiting |pelvis[t]-pelvis[t-1]| to 0.008 Blender units/frame. It must never reduce source reachability and must not exceed existing 0.20-unit cap. The pure stdlib algorithm is adversarially tested and reused by actual headless Blender on two independent public free-tier runners (neutral and shape20). The original world-space ankle targets, original native FBX matrix, foot IK, trajectory, source SHA and parent DLE remain unmodified.

**Measures:** continuous 169-frame ankle and toe movement, source-target error, per-frame body-root travel, maximum pelvic adjustment and first difference, true mesh skin motion using 0.01 original armature scale, L0 polygon-fan inversions/collapse at five independent poses; native editable .blend plus five Cycles technical frame PNGs and JSON+SHA files.
