# R014 real MHR armature locomotion retarget — research only

This is not another free-standing wireframe trajectory demo. It consumes the **exact SHA256-pinned** 169-frame Go world-space foot-contact trajectory from source [public GHA 43246188313](https://github.com/SemperSupra/stable-character-pipeline/actions/runs/43246188313) and applies it to the **actual official MHR v1.0.1 126-bone Blender armature** with bilateral lower-leg two-link IK, unparented ankle goals, keyed rig object translation/heading, independent source foot/head and ball/toe evaluation and real skinned body mesh measurements.

Two isolated disposable public cloud jobs independently test an unchanged neutral model and a native experimental `shape_20=0.25` body morph. The morph axis is **opaque and has no admitted phenotype meaning**. All model and trajectory source hashes, rig measurements, achieved planted foot and toe drift, ankle target residual, five pose-specific local-space skin foldover tests, actual keyed editable Blender scenes and sparse real 384x512 frames are archived as research. A green CI means a receipt was captured, not human locomotion accepted.

**Important limitations:** source Go planner has 0 simulated stance slip, but attaching it to real bones can produce true contact failure, unreachable targets or poor anatomy. Foot-head and toe-ball bone proxies cannot certify skin-sole contact or heel-toe rolling. MHR leg-length scaling is experimental, does not calibrate living anthropometry; variation of a shape key does not automatically re-fit the skeleton. No automatic human realism, 24fps continuous pose review, 4K materials, FACS face or full anatomical variants.

This branch depends on the original [draft MHR Blender native source #405](https://github.com/SemperSupra/stable-character-pipeline/pull/405), not on MPFB sculpt transfer or private models.
